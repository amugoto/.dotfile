# Yazi 이미지 메타데이터 상태줄 설계

## 목표

macOS의 Yazi 26 설정에 선택 파일의 메타데이터를 표시한다.

- 상태줄 오른쪽의 기본 권한 표시는 첫 항목으로 유지한다.
- 이미지: `PNG · 1920×1080 · 2.4 MiB` 형식으로 표시한다.
- 일반 파일: `PDF · 1.8 MiB` 형식으로 표시한다.
- 디렉터리는 파일 크기나 이미지 해상도를 표시하지 않는다.

## 구성

1. `dot_config/yazi/plugins/image-meta.yazi/`에 macOS 전용 메타데이터 플러그인을 둔다.
2. 플러그인은 선택 파일의 경로를 키로 하여 `sips` 결과를 캐시한다. 같은 항목에 커서를 유지하거나 다시 방문할 때 외부 명령을 반복 실행하지 않는다.
3. `dot_config/yazi/init.lua`는 기존 심볼릭 링크·현재 경로 표시를 보존하고, 플러그인이 제공하는 메타데이터를 상태줄 오른쪽에 권한 뒤 순서로 렌더링한다.
4. `dot_config/yazi/yazi.toml`은 필요한 커스텀 라인 모드/플러그인 설정만 추가한다.

## 동작과 오류 처리

- 지원 이미지 형식은 `sips`가 읽을 수 있는 형식으로 제한한다.
- `sips`가 실패하거나 해상도를 얻지 못하면 확장자와 사람이 읽기 쉬운 파일 크기만 표시한다.
- 권한은 Yazi 기본 `Status:perm`이 계속 담당한다. 기본 순서에서 권한은 오른쪽 상태줄의 첫 항목이다.
- Yazi 시작 중이나 캐시 계산 중에는 UI를 막지 않고, 사용 가능한 정보만 표시한다.

## 검증

1. PNG/JPEG 파일을 선택했을 때 형식, `가로×세로`, 사람이 읽기 쉬운 크기가 표시된다.
2. PDF·텍스트 등 비이미지 파일을 선택했을 때 형식과 크기만 표시된다.
3. 권한 표시가 메타데이터보다 앞에 유지된다.
4. `chezmoi apply` 뒤 실제 `~/.config/yazi`에서 Yazi를 재시작해 동작을 확인한다.
